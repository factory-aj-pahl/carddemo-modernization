# Mission records

The agreement and evidence record of the `/migrate` run that produced `modernization/`.

| File | Contents |
|:--|:--|
| `promise.md` | The approved outcome: scope, required properties, boundaries, and recorded decisions |
| `plan.md` | The implementation approach and sequencing |
| `validation-strategy.md` | Why the checks are sufficient for the promise |
| `checks.json` | The artifacts and the 19 checks |
| `evaluations.jsonl` | Every check evaluation, append-only (77 entries) |
| `findings.md` | Behavior findings F-1 to F-21 awaiting owner confirmation |
| `prototype/` | The clickable UI prototype approved before implementation |

Paths in these files point to the machine the run used. The evidence directory they cite (logs,
captures, and comparison outputs, about 900 MB) is not included.
